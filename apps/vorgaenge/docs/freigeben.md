# Schritte von Spezialisten freigeben

Ein **Spezialist** ist ein KI-Assistent, der Vorgänge eines Bereichs im Hintergrund
bearbeitet (App *Spezialisten*). Seine Schritte stehen im Reiter **Intern**, markiert mit
**KI**. Die meldende Person sieht davon nichts.

## Freigeben oder ablehnen

Will ein Spezialist etwas ändern – ein Werkzeug aufrufen, das etwas schreibt, oder der
meldenden Person antworten –, legt er einen **Plan** vor. Der Vorgang wartet dann auf Sie.

1. Öffnen Sie den Vorgang, Reiter **Intern**.
2. Beim Plan stehen Werkzeug und Angaben genau so, wie sie ausgeführt würden.
3. **Freigeben** (bei einem Antwortentwurf: **Veröffentlichen**) oder **Ablehnen**
   (**Verwerfen**), auf Wunsch mit Bemerkung.

Freigegeben wird genau dieser Aufruf, genau einmal. Der Spezialist selbst kann nichts
freigeben.

## Rückfragen beantworten

Fragt Sie ein Spezialist oder ein Kollege um Rat, steht im Reiter *Intern* „fragt Sie ·
offen“ mit einem Antwortfeld. Antworten Sie einmal; verantwortlich werden Sie dadurch nicht.

## Einen Spezialisten anhalten

Im Überblick: **Spezialist anhalten**. Der laufende Schritt endet, danach arbeitet an diesem
Vorgang kein Spezialist mehr, bis ihn jemand wieder zulässt.
