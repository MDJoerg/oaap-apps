# Im Chat recherchieren

So lassen Sie einen Assistenten im Internet nachsehen.

1. Öffnen Sie den **Chat** und wählen Sie einen Assistenten, der Recherche nutzen darf
   (Ihr Administrator sagt Ihnen, welcher das ist).
2. Stellen Sie das Gespräch auf **rot**. Erst dann darf der Assistent Suchwörter nach
   außen geben.
3. Stellen Sie Ihre Frage, zum Beispiel: „Welche Förderprogramme für Wärmepumpen gibt es
   2026 in Hessen? Nenne die Quellen.“
4. Der Assistent sucht mit `web_search`, liest die besten Treffer mit `web_fetch` und
   antwortet mit Links zu den Quellen.

## Tipps

- **Bitten Sie um Quellen.** Der Assistent nennt zu jeder Aussage den Link; prüfen Sie
  wichtige Angaben auf der Seite selbst.
- **Grenzen Sie ein:** „nur auf heise.de“ oder „auf Englisch“ – der Assistent gibt das an
  die Suche weiter.
- **Nichts Vertrauliches:** Kundennamen, Preise oder interne Begriffe gehören nicht in eine
  Internetsuche.
- Webseiten sind Material, keine Anweisungen: Der Assistent tut nie, was ein Seitentext
  von ihm verlangt.
