# Produkte und Dokumenttypen

## Produkte

Ein **Produkt** ist die Hilfe einer App (oder der Plattform). Die Startseite zeigt jedes
Produkt als Kachel – oder als schlichte Liste, wenn der Administrator das so eingestellt hat.
Eine Kachel nennt die Zahl der Dokumente, die Version der App und die häufigsten
Dokumenttypen.

Die Seite eines Produkts listet seine Dokumente nach Typ geordnet, mit einem Link
*Einstieg lesen* und einer Suche nur in diesem Produkt.

Der Knopf **Hilfe** in jeder App führt genau auf diese Seite.

## Dokumenttypen

| Typ | Wofür |
| --- | --- |
| Überblick | was die App tut und für wen |
| Anleitung | eine Aufgabe Schritt für Schritt |
| Schritt für Schritt | ein längerer Lernweg |
| Konzept | wie etwas gedacht ist und warum |
| Funktionsbeschreibung | was eine Funktion genau tut |
| FAQ | häufige Fragen kurz beantwortet |
| Referenz, CLI-Syntax, Schnittstelle | zum Nachschlagen |
| Fehlerbehebung | wenn etwas nicht geht |
| Betrieb | Einrichten und Betreiben |
| Neuerungen, Glossar | was sich geändert hat, was ein Wort bedeutet |

## Woher die Produkte kommen

Eine App bringt ihre Hilfe im Paket mit. Bei der Installation, jedem Update und beim
Entfernen gibt die Plattform sie an die Hilfe weiter – niemand muss etwas kopieren.
