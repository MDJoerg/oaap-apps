# Mitarbeiter finden

Die Liste hat oben eine Filterleiste:

- **Suchen** – ein oder mehrere Wörter aus Name, Abteilung oder E-Mail.
- **Abteilung** – zeigt nur die Mitarbeiter einer Abteilung.
- **Zurücksetzen** – zeigt wieder alle.

Ein Klick auf eine Spaltenüberschrift sortiert danach, ein zweiter Klick
dreht die Reihenfolge um. Bei mehr als 50 Einträgen blättern Sie mit
**Weitere 50**.

Die Adresse im Browser enthält Ihre Auswahl. Sie können eine gefilterte
Liste also als Lesezeichen speichern oder den Link weitergeben.
