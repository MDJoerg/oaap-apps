# Läufe verfolgen

Ein **Lauf** ist ein Arbeitsgang eines Spezialisten an einem Vorgang.

## In der App

Der Reiter **Läufe** zeigt jeden Lauf mit Beginn, Spezialist, Vorgang, Zahl der Schritte und
wie er endete:

| Ende | Bedeutung |
| --- | --- |
| fertig, zurückgegeben | er hat seine Arbeit getan und an die Zuständigen zurückgegeben |
| wartet auf Freigabe | er hat einen Plan vorgelegt, ein Mensch muss ihn freigeben |
| wartet auf Rückmeldung | er hat eine Rückfrage gestellt |
| Grenze, zurückgegeben | Schritte oder Minuten reichten nicht |
| Läufe je Vorgang erreicht | zu viele Läufe an diesem Vorgang |
| Fehler, zurückgegeben | etwas ging schief, der Vorgang liegt wieder bei den Zuständigen |
| angehalten | jemand hat am Vorgang „Spezialist anhalten“ gedrückt |
| läuft | gerade in Arbeit |

Filtern Sie nach Spezialist oder Ende, suchen Sie nach einer Vorgangsnummer, und sortieren
Sie per Klick auf eine Spalte. Die Adresse merkt sich den Filter – Sie können sie als
Lesezeichen speichern oder weitergeben.

## Im Vorgang

Was ein Lauf genau getan hat, steht **intern** im Vorgang: jede Notiz, jeder
Werkzeugaufruf, am Ende der Grund. Dort halten Sie einen Spezialisten auch an.

## Über den Chat

Ein Assistent mit Zugriff auf die Spezialisten kann fragen: „Wie liefen die letzten Läufe
von Analyse (KI)?“ Er liest dieselben Angaben wie diese Seite.
