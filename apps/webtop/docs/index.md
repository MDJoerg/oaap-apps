# Desktop im Browser (Webtop) – Überblick

Ein ganzer **Linux-Desktop im Browser**. Er läuft auf dem Server, Dein
Browser zeigt ihn nur. So kannst Du Programme benutzen, die ein eigenes
Fenster brauchen – ohne etwas auf Deinem Rechner zu installieren.

## Für wen

- Teilnehmende einer Schulung: Jede Person hat ihren eigenen Desktop.
- Alle, die Werkzeuge wie Eclipse mit den ABAP Development Tools brauchen,
  deren Laptop aber keine Installation erlaubt.

## Was Du bekommst

- **Deinen eigenen Desktop** mit eigenem Speicher. Die Sitzung läuft weiter,
  wenn Du den Browser schließt – beim nächsten Öffnen stehen die Fenster
  noch da.
- **Vorinstallierte Werkzeuge**: Eclipse mit ABAP Development Tools und ABAP
  Cleaner, VS Code, Claude Code und Claude Desktop, goose und opencode,
  Google Chrome und Firefox.
- **Material** vom Betreiber im Ordner „Material“ auf dem Desktop.
- **Keine zweite Anmeldung**: Du meldest Dich einmal bei der Plattform an.

Auf dem Desktop liegt die Datei **ARBEITSPLATZ-INFO.txt** mit Deinem
Benutzer, der Version und – falls eingerichtet – den Angaben zum SAP-System.
