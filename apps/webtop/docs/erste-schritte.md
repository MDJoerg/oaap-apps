# Erste Schritte

## Öffnen

1. Melde Dich im Portal an.
2. Klicke auf die Kachel **Desktop im Browser (Webtop)**. In einer Schulung
   siehst Du dort nur Deinen eigenen Desktop.
3. Der Desktop erscheint im Browser-Reiter.

Der allererste Start dauert ein paar Minuten, weil der Desktop eingerichtet
wird. Danach ist er schnell da.

## Auf dem Desktop

- **ARBEITSPLATZ-INFO.txt** – Dein Benutzer, die Version, die Werkzeuge und
  die Verbindung zum SAP-System.
- **Verknüpfungen** für Eclipse, VS Code, Claude Desktop, goose, Chrome und
  Firefox.
- **Material** – Unterlagen vom Betreiber.
- Deine Projekte liegen in `~/projekte`.

## Gut zu wissen

- **Browser schließen ist kein Abmelden.** Die Sitzung läuft im Container
  weiter. Speichere trotzdem regelmäßig.
- **Kopieren und Einfügen** zwischen Deinem Rechner und dem Desktop geht
  über das Seitenmenü der Bildübertragung im Browser-Reiter.
- **Eigene Web-Apps** testest Du im Chrome auf dem Desktop, zum Beispiel
  unter `http://localhost:5173`. Die Ports 3000 und 3001 belegt der Desktop
  selbst.
- **Neustart des Servers**: Plant der Betrieb einen Neustart, erscheint
  rechtzeitig eine Meldung und die Datei `NEUSTART-GEPLANT.txt` auf dem
  Desktop. Sichere dann Deine Arbeit.

## Zurück zum Portal

Öffne das Portal in einem anderen Reiter. Der Desktop selbst hat keinen
Link dorthin.
