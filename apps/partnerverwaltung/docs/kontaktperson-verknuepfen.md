# Eine Kontaktperson mit einer Firma verknüpfen

Eine Kontaktperson wird zum **Ansprechpartner** einer Firma, wenn Sie beide
verknüpfen.

1. Öffnen Sie die Seite der Kontaktperson (Bereich **Kontaktpersonen**, Klick
   auf den Namen).
2. Wählen Sie im Abschnitt **Mit Firma verknüpfen** die Firma aus der Liste.
3. Setzen Sie bei **Gültig ab** das Datum, seit dem die Person Ansprechpartner
   ist. Vorgeschlagen ist heute.
4. Klicken Sie auf **Verknüpfen**.

Die Person erscheint danach auf der Seite der Firma unter **Ansprechpartner**,
und in der Liste der Kontaktpersonen steht die Firma in der Spalte „Firma“.

Eine Person kann Ansprechpartner mehrerer Firmen sein.
