# Einen Link anlegen

1. Reiter **Meine Links** → **Neuer Link**.
2. Wählen Sie die **Area**. Sie bestimmt den Typ (Weiterleitung, Zählpixel,
   Download, Upload) und die Regeln.
3. Füllen Sie aus, was der Typ braucht – bei einer Weiterleitung die
   **Ziel-URL** (mit `http://` oder `https://`).
4. Auf Wunsch: **Titel** (nur für Sie sichtbar), **PIN**, **Gültig bis**, **Notiz**.
5. **Anlegen**. Sie landen auf der Seite des Links.

## Auf der Seite des Links

- Die **öffentliche Adresse** mit **Kopieren**. Hat die Instanz mehrere Adressen,
  wählen Sie oben, welche gezeigt wird.
- Der **QR-Code** zum Herunterladen als PNG oder SVG (nicht beim Zählpixel).
- **Bearbeiten**: Titel, Notiz, Ablauf, Ziel; **PIN setzen** oder entfernen;
  **Deaktivieren** und wieder aktivieren; **Löschen**.
- Die **Statistik**, siehe [Statistik lesen](statistik.md).

## Wunsch-Keys

Den Teil hinter der Area (den *Key*) erzeugt der Wegweiser. Einen eigenen Key wie
`sommerfest` vergeben nur Verantwortliche der Area, und nur wenn die Area es
erlaubt. Ein Key besteht aus Buchstaben und Ziffern, höchstens 8 Zeichen;
Groß- und Kleinschreibung spielt keine Rolle.

## PIN

Ein Link mit PIN zeigt erst eine Seite mit PIN-Feld. Fünf falsche Eingaben
sperren den Link 15 Minuten, jede weitere Sperre dauert doppelt so lang.
Manche Areas verlangen eine PIN; die Mindestlänge legt die Area fest.

## Liste durchsuchen

In **Meine Links** finden Sie Links über das Suchfeld (Key, Titel, Ziel), filtern
nach **Status** (aktiv, abgelaufen, deaktiviert …) und sortieren per Klick auf die
Spaltenüberschrift. Ab 50 Links blättern Sie mit **Weitere 50**.
