# Dateien übergeben

## Eine Datei zum Herunterladen geben

1. **Neuer Link** in einer Area vom Typ *Einmal-Download* oder
   *Zeitraum-Download* anlegen. Beim Zeitraum-Download können Sie **Download ab**,
   **Download bis** und eine **Höchstzahl** an Downloads setzen.
2. Auf der Seite des Links unter **Datei** die Datei wählen und **Anhängen**.
   Eine neue Datei ersetzt die alte. Größe und erlaubte Endungen bestimmt die
   Area.
3. Die Adresse (oder den QR-Code) weitergeben.

Wer die Adresse öffnet, sieht Name, Größe und Prüfsumme (SHA-256) der Datei und
einen Knopf **Herunterladen**. Erst der Knopf zählt. Ist ein Einmal-Download
abgeholt, entfernt der Wegweiser die Datei; der Eintrag bleibt mit Namen und
Zahlen.

## Sich eine Datei schicken lassen

1. **Neuer Link** in einer Area vom Typ *Einmal-Upload* anlegen, auf Wunsch mit
   PIN.
2. Die Adresse an die Person schicken, die Ihnen die Datei geben soll.
3. Sie wählt genau eine Datei und lädt sie hoch. Danach ist der Link verbraucht.
4. Die Seite des Links zeigt **Eingegangene Datei** zum Herunterladen.

Mit **Datei entfernen** über die REST-API wartet ein Upload-Link wieder auf eine
neue Datei.
