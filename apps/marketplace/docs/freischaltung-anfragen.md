# Eine Freischaltung anfragen

Ein Asset, das du sehen, aber nicht laden darfst, trägt das Zeichen
**freischalten**.

1. Melde dich an (oben rechts **Anmelden**), falls noch nicht geschehen.
2. Öffne die Detailseite des Assets und wähle **Freischaltung anfragen**.
3. Wähle den Kanal (zum Beispiel `stable`) und schreibe kurz, wofür du das
   Asset brauchst.
4. **Anfrage senden.** Du hast je Asset eine offene Anfrage; eine zweite
   ergänzt die erste.

Die Antwort siehst du auf derselben Detailseite:

- **Freigeschaltet** – der Knopf **Laden** erscheint. Manchmal steht ein Link
  dabei, zum Beispiel eine Einladung.
- **Abgelehnt** – mit der Begründung des Betreibers oder Anbieters.

Entscheiden kann der Betreiber in der Verwaltung oder der Anbieter des Assets
unter **Meine Assets**.
