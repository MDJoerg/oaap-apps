# Häufige Fragen

**Ich habe eine Version hochgeladen, aber im Store ist sie nicht zu sehen.**
Hochgeladen heißt noch nicht freigegeben. Öffne die App und klicke bei der
Version auf **Freigeben**. Prüfe außerdem **Sichtbar für**.

**Kann ich eine Version korrigieren und noch einmal hochladen?**
Nein, eine Version wird nie überschrieben. Erhöhe die Versionsnummer im Manifest
des Pakets und lade die neue Version hoch.

**Warum steht 1.2.10 über 1.2.9?**
Versionen werden nach Zahlen geordnet, nicht nach Buchstaben.

**Was passiert mit laufenden Instanzen, wenn ich eine Version zurückziehe?**
Nichts. Zurückziehen nimmt die Version nur aus dem Store.

**Warum verlangt Löschen manchmal einen Grund?**
Eine freigegebene Version war für Mandanten sichtbar. Der Grund bleibt im
Protokoll, damit später nachvollziehbar ist, warum sie fehlt.

**Was bedeutet „vom Knoten“?**
Das Paket kam aus dem Portal („In den Katalog übernehmen“) und nicht über
Hochladen.

**Kann eine KI im Chat den Katalog lesen?**
Ja, für Betreiber: Der Katalog hat eine lesende MCP-Schnittstelle. Ein Assistent
kann Pakete auflisten und den Stand einer App lesen. Freigeben oder Löschen kann
er nicht.

**Wer darf den Katalog benutzen?**
Nur die Rolle `admin`.
