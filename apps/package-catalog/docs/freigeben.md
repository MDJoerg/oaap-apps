# Freigeben und zurückziehen

Auf der **Seite einer App** stehen alle Versionen, die neueste oben. Ein Klick
auf eine Version wählt sie aus; darunter stehen ihre Angaben und Handlungen.

- **Freigeben** – die Version kommt in die Liste, die der Knoten liest. Ist sie
  die höchste freigegebene, sehen Mandanten-Administratoren sie im Store.
- **Zurückziehen** – sie verschwindet aus dem Store. Laufende Instanzen bleiben
  unberührt; nur neue Installationen und Aktualisierungen bekommen sie nicht mehr.
- **Laden** – lädt genau die hochgeladene ZIP herunter.
- **Löschen** – entfernt die Version mit ihrer Datei. Eine **freigegebene**
  Version zu löschen verlangt einen **Grund**; er bleibt im Protokoll. Ist es
  die letzte Version, verschwindet die App aus dem Katalog.

## Was der Status in der Übersicht bedeutet

- **freigegeben 1.2.0** – diese Version steht im Store.
- **1.3.0 wartet** – eine neuere Version ist hochgeladen, aber noch nicht
  freigegeben.
- **nichts freigegeben** – die App steht nicht im Store.
- **im Marktplatz zurückgerufen** – der angebundene Marktplatz hat diese Version
  zurückgerufen. Prüfe, ob Du sie zurückziehen willst.
