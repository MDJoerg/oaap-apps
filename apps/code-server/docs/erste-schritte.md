# Erste Schritte

## Öffnen

1. Melde Dich im Portal an.
2. Klicke auf die Kachel **Entwicklungsumgebung (VS Code)**. In einer
   Schulung siehst Du dort nur Deinen eigenen Arbeitsplatz.
3. VS Code öffnet sich im Browser mit dem Ordner `projects`.

Der erste Start kann etwas dauern, weil die Erweiterungen in Deinen
Speicher kopiert werden. Danach geht es schnell.

## Arbeiten

- **Terminal**: Menü *Terminal → Neues Terminal*.
- **Projekt holen**: im Terminal `git clone <adresse>` im Ordner
  `projects`.
- **Kursmaterial**: liegt im Ordner `material`.
- **Eigener Entwicklungsserver**: Startest Du im Terminal einen Server, zum
  Beispiel auf Port 4004, erreichst Du ihn unter derselben Adresse mit
  `/proxy/4004/` am Ende – mit derselben Anmeldung.

## Tipps für den Browser

- Manche Tastenkürzel fängt der Browser ab, etwa `Strg+W` (schließt den
  Reiter). VS Code bietet „App installieren“ an; dann läuft es in einem
  eigenen Fenster, und die Kürzel gehören VS Code. Dafür brauchst Du keine
  Rechte auf Deinem Rechner.
- Schließt Du den Browser, bleibt alles gespeichert. Beim nächsten Öffnen
  geht es weiter.

## Zurück zum Portal

Öffne das Portal in einem anderen Reiter oder über die Adresse Deines
Mandanten. VS Code selbst hat keinen Link dorthin.
