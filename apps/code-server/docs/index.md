# Entwicklungsumgebung (VS Code) – Überblick

Die Entwicklungsumgebung ist **VS Code im Browser**. Das Programm läuft
auf dem Server, Dein Browser zeigt es nur. Du musst auf Deinem Rechner
nichts installieren – praktisch für Schulungen und für alle, deren Laptop
keine Installation erlaubt.

## Für wen

- Teilnehmende einer Schulung: Jede Person hat ihren eigenen Arbeitsplatz.
- Alle, die eine vorbereitete Entwicklungsumgebung brauchen, etwa für SAP
  CAP, ABAP oder kleine Web-Apps.

## Was Du bekommst

- **Deinen eigenen Arbeitsplatz** mit eigenem Speicher. Projekte,
  Einstellungen und Erweiterungen bleiben erhalten, auch wenn Du den Browser
  schließt.
- **Ein Terminal** mit git, Node.js, Python und den üblichen Werkzeugen.
- **Vorinstallierte Erweiterungen**: Claude Code, ABAP Remote Filesystem und
  SAP CDS Language Support. Weitere legt die Verwaltung fest.
- **Kursmaterial** im Ordner `material`, getrennt von Deinen Projekten.
- **Keine zweite Anmeldung**: Du meldest Dich einmal bei der Plattform an.
