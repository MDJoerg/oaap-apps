# Willkommen in deinem Arbeitsplatz

Das hier ist VS Code im Browser (code-server), bereitgestellt von der
OAAP-Plattform. Alles, was du unter `~/projects` ablegst, bleibt
erhalten, bis dein Arbeitsplatz abgeräumt wird.

## Was du hast

- **Terminal:** Menü → Terminal → Neues Terminal (oder `Strg+ö`). Du bist
  Benutzer `coder`; `sudo apt install …` funktioniert, wenn der Betreiber
  es nicht abgeschaltet hat.
- **Werkzeuge:** git, Node.js + npm, Python 3, jq, zip/unzip.
- **Erweiterungen (vorinstalliert):** Claude Code, ABAP Remote Filesystem,
  SAP CDS Language Support. Weitere findest du im Erweiterungs-Menü; die
  Quelle ist Open VSX, nicht der Microsoft-Marktplatz.
- **Kursmaterial:** liegt unter `~/material`, wenn dein Trainer welches
  bereitgestellt hat.

## Hinweise für den Browser

- Ein paar Tastenkürzel fängt der Browser ab (`Strg+W` schließt den Tab).
  Tipp: Menü → „App installieren" (PWA), dann verhält sich das Fenster wie
  ein Programm.
- Ein Entwicklungsserver, den du im Terminal startest (z. B. Port 4004),
  ist im Browser unter `…/proxy/4004/` erreichbar.

## Claude Code

Klick links auf das Claude-Symbol oder tippe `claude` im Terminal. Hat der
Betreiber einen API-Schlüssel hinterlegt, bist du direkt angemeldet;
sonst führt dich die Erweiterung durch die Anmeldung.
