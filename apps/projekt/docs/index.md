# Projekte – Überblick

Die App **Projekte** zeigt alle Projekte Ihres Betriebs: für welchen Kunden,
in welchem Stand, seit wann.

Die Projekte liegen im **digitalen Zwilling** Ihres Mandanten, dem
gemeinsamen Datenbestand aller Apps. Projekte entstehen an zwei Stellen:

- hier, mit **Neues Projekt**,
- in der **Partnerverwaltung**, auf der Seite einer Firma.

Die Liste zeigt beide; die Spalte **Angelegt von** sagt, woher ein Projekt
kommt. Der **Kunde** ist immer eine Firma aus der Partnerverwaltung – Sie
wählen sie aus einer Liste.

## Für wen

Für alle, die Projekte planen, begleiten oder einfach wissen wollen, was für
welchen Kunden läuft.
