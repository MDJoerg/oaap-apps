# Projekte finden

Die Liste hat oben eine Filterleiste:

- **Suchen** – Wörter aus Titel, Kunde oder Status.
- **Status** – nur Projekte in einem Stand.
- **Kunde (Firma)** – nur die Projekte einer Firma.
- **Angelegt von** – nur Projekte aus dieser App oder aus der
  Partnerverwaltung.
- **Zurücksetzen** – zeigt wieder alle.

Ein Klick auf eine Spaltenüberschrift sortiert, ein zweiter dreht die
Reihenfolge um. Bei mehr als 50 Projekten blättern Sie mit **Weitere 50**.
Die Adresse enthält die Auswahl – speichern Sie sie als Lesezeichen.
