# Eine Rolle anlegen

1. Öffnen Sie den Reiter **Rollen** und klicken Sie auf **Neue Rolle**.
2. Sie sehen je installierter App die Vorlagen, die diese App anbietet.
3. Geben Sie der Rolle einen Namen, den Ihre Leute verstehen („Redaktion News“).
4. Kreuzen Sie die Werte an, für die die Rolle gelten soll (mindestens einen).
5. **Rolle anlegen**.

Danach bündeln Sie die Rolle in ein Paket:

1. Reiter **Berechtigungspakete** → **Neues Berechtigungspaket**.
2. Name eingeben, Rollen ankreuzen, **Berechtigungspaket anlegen**.

## Ausblenden

Eine Rolle oder ein Paket, das nicht mehr gebraucht wird, öffnen Sie mit einem
Klick und wählen **Ausblenden**. Ausblenden löscht nichts.

- Ein Paket lässt sich erst ausblenden, wenn keine gültige Zuordnung und keine
  Gruppe mehr darauf steht.
- Eine Rolle erst, wenn kein sichtbares Paket sie mehr enthält.

Der Anmeldedienst sagt, was im Weg steht. Ausgeblendetes zeigt die Liste mit
**auch ausgeblendete zeigen**.
