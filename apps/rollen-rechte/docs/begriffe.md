# Die Begriffe

Vier Begriffe tragen die ganze App.

**Rolle** – eine fachliche Rolle, die eine App vorgibt („Trainer/in“, „Bereich“),
mit den Werten, die Ihr Mandant einsetzt („Bereich: News“). Eine Rolle allein
gibt noch niemandem etwas.

**Berechtigungspaket** – ein Bündel von Rollen, auch aus mehreren Apps. Nur Pakete
werden Personen gegeben, nie einzelne Rollen. So bekommt eine neue Trainerin mit
einem Klick alles, was zu ihrer Aufgabe gehört.

**Zuordnung** – Person + Paket, auf Wunsch mit Zeitraum (von, bis). Verlangt eine
Rolle im Paket es, sagt „Gilt für“, *wofür* das Recht gilt – zum Beispiel für
eine bestimmte Mannschaft.

**Gruppe des Anmeldedienstes** – eine Gruppe, die im Anmeldedienst gepflegt wird
(z. B. `Verein/Hallenwart`). Sie kann ein Paket geben; gelesen wird bei jeder
Anmeldung neu.

Dazu:

**Weitergabe** – manche Rollen erlauben, ein Recht selbst weiterzugeben (etwa der
Teamchef an eine Helferin). Das geschieht in der jeweiligen App, ohne Admin. Hier
sehen Sie, was weitergegeben wurde.

**Agent** – ein Maschinenkonto mit eigenen Zuordnungen. Es darf, was ihm
zugeordnet ist, nicht was die Person darf, die es einsetzt. Ein Agent gibt nichts
weiter.
