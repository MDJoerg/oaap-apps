# Rechte über Gruppen

Statt jeder Person einzeln ein Paket zu geben, kann eine **Gruppe des
Anmeldedienstes** ein Paket geben – zum Beispiel bekommt jedes Mitglied der Gruppe
`Verein/Hallenwart` das Paket „Hallenwart“.

## Eine Abbildung anlegen

1. Reiter **Gruppen → Paket** → **Neue Abbildung**.
2. Den **Pfad der Gruppe** eintragen, genau wie im Anmeldedienst
   (`Verein/Hallenwart`).
3. Das **Berechtigungspaket** wählen und **Zuordnen**.

## Gut zu wissen

- Die Gruppen selbst pflegt der Anmeldedienst, nicht diese App. Eine Person kann
  in mehreren Gruppen sein.
- Gelesen wird **bei jeder Anmeldung**. Eine Änderung wirkt beim nächsten Login
  der Person, nicht sofort.
- Eine umbenannte Gruppe gibt nichts mehr – passen Sie dann die Abbildung an.
- Entfernen Sie eine Abbildung (anklicken → **Entfernen**), endet sofort, was sie
  gab.
- Pakete, bei denen „Gilt für“ auszufüllen ist, lassen sich nicht über eine
  Gruppe geben.
