# Ein Modell holen

Nur für Administratoren.

1. Öffne die **Übersicht**.
2. Trage im Kasten **Modell holen** den Namen ein, wie er auf ollama.com steht, zum
   Beispiel `qwen2.5:3b`. Ohne Doppelpunkt nimmt Ollama die Fassung `latest`.
   Ein Klick auf einen der **bewährten Startpunkte** trägt den Namen für dich ein.
3. Klicke auf **Holen**.

Oben erscheint der Kasten **Wird geholt** mit einem Fortschrittsbalken. Die Seite
aktualisiert sich alle paar Sekunden selbst. Du darfst die Seite verlassen – geholt wird
auf dem Knoten, nicht im Browser.

## Welche Größe?

Auf einem Knoten ohne Grafikkarte entscheidet die Größe, ob ein Modell benutzbar ist.
Modelle um 2 GB antworten in Sekunden; sehr große Modelle brauchen Minuten für einen Satz.
