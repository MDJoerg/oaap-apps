# Eine Kohorte für eine Schulung anlegen

Eine Kohorte sind viele Schlüssel auf einmal – je Teilnehmer einer, alle mit demselben Ende.

1. Öffne den Reiter **Kohorten**.
2. Trage einen Namen für die Kohorte ein, zum Beispiel `kurs-2026-11`, und das Datum, bis zu
   dem die Schlüssel gelten.
3. Füge die **Teilnehmer** ein, eine Zeile je Person – direkt aus Excel oder einer Liste.
   Erste Spalte: der Name. Eine Nummer in der zweiten Spalte gilt als Kennung; sonst wird
   fortlaufend gezählt.
4. Optional: Projekt, Kostenstelle, Budget je Teilnehmer, Ampel und erlaubte Modellnamen.
5. Klicke auf **Schlüssel erzeugen**.

Zurück kommt dieselbe Tabelle mit einer Spalte für den Schlüssel – als Text zum
Zurückkopieren und als CSV-Datei. **Nur dieses eine Mal.**

## Verlängern oder beenden

Klicke in der Liste auf die Kohorte. Dort kannst du **verlängern** (auch abgelaufene Schlüssel
gelten danach wieder) oder **alle widerrufen**. Einen einzelnen Teilnehmer widerrufst du, indem
du auf seine Kennung klickst.

Der Name einer Zeile wird zum „Verantwortlichen“ des Schlüssels und steht in der Auswertung.
Wer das nicht möchte, fügt Kürzel ein.
